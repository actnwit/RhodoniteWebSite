Rhodoniteは以下の2通りの方法で導入できます。

## npmリポジトリを利用する方法

Rhodoniteはnpmを用いて導入することができます。

### npmを用いたRhodoniteのインストール

ターミナルから以下のコマンドでRhodoniteをインストールできます。

```bash
$ npm install rhodonite
```

### Bundlerを使った場合のコーディング例

WebpackやViteなどのバンドラーを使うことで、Rhodoniteを容易にimportして利用することができます。
以下はTypeScriptを用いた一例です。

```ts
// main.ts
import Rn from 'rhodonite';

document.body.onload = async function load() {
  const engine = await Rn.Engine.init({
    approach: Rn.ProcessApproach.WebGL2,
    canvas: document.getElementById('world') as HTMLCanvasElement,
  });

  // 3Dモデルの読み込みやdrawコールなど
}
```

### ツリーシェイキングとバンドルサイズ

ESModule版（`dist/esm`、`dist/esmdev`）はソースモジュールごとに1ファイルを保持し、パッケージの`sideEffects`は共有依存チャンクのみを宣言しています。そのため、Vite、Rollup、Rolldown、webpack、esbuildなどのバンドラーは、アプリケーションが使用しないRhodoniteの部分をバンドルから除外できます。使用するAPIは名前付きでimportします。

```ts
// main.ts
import { Engine, MeshHelper, ProcessApproach, Vector3 } from 'rhodonite';

document.body.onload = async function load() {
  const engine = await Engine.init({
    approach: ProcessApproach.WebGL2,
    canvas: document.getElementById('world') as HTMLCanvasElement,
  });

  const planeEntity = MeshHelper.createPlane(engine);
  planeEntity.eulerAngles = Vector3.fromCopy3(Math.PI * 0.5, 0, 0);
};
```

デフォルトエクスポートの`Rn`はすべてのエクスポートを参照するため、`import Rn from 'rhodonite'`は常にライブラリ全体をバンドルします。同様に`MaterialHelper`はすべてのマテリアルファクトリを参照するので、代わりにファクトリ関数を直接importしてください（例: `import { createPbrUberMaterial } from 'rhodonite'`）。

ノードベースのマテリアルとMToonは`rhodonite/optional-materials`サブパスからエクスポートされるため、それらを使わないアプリケーションのバンドルには含まれません。

```ts
import { createMToon1Material } from 'rhodonite/optional-materials';
```

名前付きimportを使う場合、次の2つのオプション機能は明示的に有効化する必要があります（デフォルトエクスポートの`Rn`を使う場合は自動的に有効になります）。

```ts
import { Engine, ProcessApproach, registerGizmos } from 'rhodonite';

// ギズモ（isTranslationGizmoVisible、isLightGizmoVisibleなど）
registerGizmos();

// WebXR / WebAR対応。後から`await engine.enableXR()`で有効化することもできます
const engine = await Engine.init({
  approach: ProcessApproach.WebGL2,
  canvas: document.getElementById('world') as HTMLCanvasElement,
  xr: true,
});
```

アプリケーションが使用しないレンダリングバックエンドのシェーダーを除外するには、バンドラーでフラグを定義します。`__RN_WEBGPU__: false`でWebGL2専用のバンドルを、`__RN_WEBGL__: false`でWebGPU専用のバンドルを生成できます。フラグを指定しない場合、両方のバックエンドのシェーダーが含まれます。

```js
// vite.config.js (WebGL2のみ)
export default {
  define: { __RN_WEBGPU__: false },
};
```

`esbuild`も同じ`define`オプションを受け付け、webpackでは`new webpack.DefinePlugin({ __RN_WEBGPU__: false })`を使います。除外したプロセスアプローチを要求すると、`Engine.init`はエラーを投げます。

コンポーネントクラスはライブラリのimport時ではなく、エンティティに最初に追加されたときに登録されます。`EntityRepository.tryToAddComponentToEntityByTID()`が見つけられるのは、コアのコンポーネントクラス（Transform、SceneGraph、Mesh、MeshRenderer、Camera、CameraController、Light、Animation）と、それ以前に追加されたクラスだけです。それ以外のコンポーネントは、クラスを`EntityRepository.addComponentToEntity()`に渡してください。

> **注:** 非バンドル形式のESModuleビルドと`rhodonite/optional-materials`サブパスは、最新のRhodoniteTS開発版に含まれます。それ以前のnpmリリースでは、`import Rn from 'rhodonite'`がエントリーポイントです。

### Bundlerを使わない場合

Bundlerを使わないで利用することもできます。以下はTypeScriptでの例です。

```html
<!-- index.html -->
...
<script type="module" src="main.js">
...
```

```ts
// main.ts
import Rn from 'node_modules/rhodonite/dist/esm/index.js'; // ESModuleとして利用
// import Rn from 'node_modules/rhodonite/dist/esmdev/index.js'; // ライブラリ内のソースマップ表示やステップ実行をしたい場合はこちらを使う

document.body.onload = async function load() {
  const engine = await Rn.Engine.init({
    approach: Rn.ProcessApproach.WebGL2,
    canvas: document.getElementById('world') as HTMLCanvasElement,
  });

  // 3Dモデルの読み込みやdrawコールなど
}
```

```
// tsconfig.json
{
  ...
  "compilerOptions": {
    "module": "ESNext",
    "moduleResolution": "node",
    "esModuleInterop": true,
    ...
  }
  ...
}
```

## GitHubリポジトリ内のランタイムを使用する方法

この方法では、導入したいプロジェクトフォルダーにRhodoniteランタイム（実行用のjsファイル）をコピーし、それを参照して利用します。

### Rhodoniteランタイムのコピー

RhodoniteのGitHubリポジトリには`dist`ディレクトリが存在します。
リポジトリをCloneしてbuildを行うと（Node.js 22以降とpnpmが必要です）、`dist/iife`および`dist/iifedev`ディレクトリ以下にRhodoniteランタイムが生成されます。

```bash
$ pnpm install
$ pnpm run build
```

![dist_dir](https://user-images.githubusercontent.com/3821214/161363331-ff417948-228b-460e-a11a-2cc8481f6df0.png)

または、CI(自動テスト)結果ページ([https://github.com/actnwit/RhodoniteTS/actions/workflows/test.yml](https://github.com/actnwit/RhodoniteTS/actions/workflows/test.yml))のテストが成功したリンク先のArtifactの欄からdistフォルダの内容をZipダウンロードして入手することも可能です。
![image](https://user-images.githubusercontent.com/3821214/161414183-1d070606-771a-47e4-b5c3-330bcd5170d9.png)

`dist/iifedev`ディレクトリ内の`rhodonite.js`（開発用ビルド）、または`dist/iife`ディレクトリ内のminify版`rhodonite.min.js`をプロジェクトフォルダー以下にコピーします。以下では`rhodonite.js`を用いた例を扱いますが、`rhodonite.min.js`に読み換えても問題ありません。

### JavaScriptを用いたコーディング例

htmlファイルから`rhodonite.js`を参照することで、グローバルオブジェクト(window)のRnプロパティからRhodoniteを使えます。
この場合、RhodoniteのIIFE版を利用していることになります。

たとえば、プロジェクトフォルダーが次の画像のように構成されているとします。

![use_runtime_directory](https://user-images.githubusercontent.com/3821214/161363360-26add3ca-54b2-4173-bf2c-aeb4add8168e.png)

このとき、`index.html`から次のようにRhodoniteを利用できます。

```html
// index.html
<body>
  <canvas id="world"></canvas>
  <script src="./rhodonite.js"></script>
  <script>
    document.body.onload = async function load() {
      const engine = await Rn.Engine.init({
        approach: Rn.ProcessApproach.WebGL2,
        canvas: document.getElementById('world'),
      });

      // 3Dモデルの読み込みやdrawコールなど
    }
  </script>
</body>
```

TypeScriptを使う場合は次のようにします。
IIFE版ではRhodoniteの型の運用が通常よりも変則的になります。
TypeScriptでコーディングする場合は、ESModule版の利用を推奨します。

```ts
import _Rn from 'rhodonite'; // Use this for adding type annotations to window.Rn in this sample
import { CameraComponent, RenderPass } from 'rhodonite'; // for type annotations for iife usage

declare const window: any;
declare const Rn: typeof _Rn; // Use the window.Rn as Rn


async function load() {
  const engine = await Rn.Engine.init({
    approach: Rn.ProcessApproach.WebGL2,
    canvas: document.getElementById('world') as HTMLCanvasElement
  });

  // Camera
  const cameraEntity = Rn.createCameraControllerEntity(engine, true);
  const cameraComponent: CameraComponent = cameraEntity.getCamera();

  ...
  (After that, please refer to the sample codes.)
  ...

```

TypeScriptコードを次のようにコンパイルします。

```bash
$ npx tsc ./main.ts --lib es2015,dom --target es2015 --module umd --moduleResolution node
```

TypeScriptコードをUMDとしてコンパイルしたので、それをブラウザで読み込むためにreqiurejsなどを利用します。

```html
<script src="./rhodonite.js"></script>
<script src="https://cdnjs.cloudflare.com/ajax/libs/require.js/2.3.6/require.min.js" data-main="main.js"></script>
```
