チュートリアルは以上ですが、もっと参考となるコードが欲しい場合は、Rhodoniteプロジェクトの[samples](https://github.com/actnwit/RhodoniteTS/tree/main/samples)ディレクトリを覗いてください。様々なサンプルのソースコードがあるのでコーディングの際の参考となるでしょう。

Rhodoniteプロジェクトをcloneし、プロジェクト直下で以下のコマンドを打つと、ライブラリとサンプルがビルドされ、ローカルサーバーが起動します（Node.js 22以降とpnpmが必要です）。

```bash
$ pnpm install
$ pnpm run build
$ pnpm run watch-samples
```

`http://localhost:8082`にアクセスすると、実際のサンプルの動作を確認することができます。終了するときはctrl + cを押してください。
