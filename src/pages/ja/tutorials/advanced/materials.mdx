## Materialの作成

Rhodoniteには多くのマテリアルクラスがあります。これらを生成するには、ヘルパーオブジェクトである[MaterialHelper](https://actnwit.github.io/RhodoniteTS/api/variables/default.MaterialHelper.html)を使います。

```typescript
const material = Rn.MaterialHelper.createPbrUberMaterial(engine);
```

### ツリーシェイキングのためのマテリアルファクトリのimport

`MaterialHelper`はすべてのマテリアルファクトリを参照するため、これを使うとすべてのマテリアルがバンドルに含まれます。使用しないマテリアルをバンドラーに除外させるには、ファクトリ関数を直接importしてください。

```typescript
import { createPbrUberMaterial } from 'rhodonite';

const material = createPbrUberMaterial(engine);
```

ノードベースのマテリアルとMToonは`rhodonite/optional-materials`サブパスからエクスポートされています（例: `import { createMToon1Material } from 'rhodonite/optional-materials'`）。

## Materialへのシェーダーパラメーター設定

シェーダーパラメータの設定は、そのシェーダーを保持している[Material](https://actnwit.github.io/RhodoniteTS/api/classes/default.Material.html)クラスに対して行います。

```typescript
material.setParameter("baseColorFactor", Rn.Vector4.fromCopy4(1, 1, 1, 1));
```

テクスチャをシェーダーに渡す場合は、以下のようにします。

```typescript
const rnTexture = await Rn.Texture.loadFromUrl(engine, '/path/to/texture.png');

const rnSampler = new Rn.Sampler(engine, {
   magFilter: Rn.TextureParameter.Linear,
   minFilter: Rn.TextureParameter.Linear,
   wrapS: Rn.TextureParameter.ClampToEdge,
   wrapT: Rn.TextureParameter.ClampToEdge,
});
rnSampler.create();

material.setTextureParameter("baseColorTexture", rnTexture, rnSampler);
```

## Materialの適用

作成したMaterialは[Primitive](https://actnwit.github.io/RhodoniteTS/api/classes/default.Primitive.html)や[MeshHelper](https://actnwit.github.io/RhodoniteTS/api/variables/default.MeshHelper.html)オブジェクトのメソッド群で使用することができます。
それらのPrimitiveや[Mesh](https://actnwit.github.io/RhodoniteTS/api/classes/default.Mesh.html)は指定されたMaterialが適用されて描画されます。

```typescript
const primitive = Rn.Primitive.createPrimitive(engine, {
  indices: indices,
  attributeSemantics: [Rn.VertexAttribute.Position.XYZ],
  attributes: [positions],
  primitiveMode: Rn.PrimitiveMode.Lines,
});
primitive.material = material;
```

```typescript
const sphere = Rn.MeshHelper.createSphere(engine, {
    radius: 1,
    widthSegments: 10,
    heightSegments: 10,
    material: material
  })
```
