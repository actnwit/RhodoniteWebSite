RhodoniteでのglTFの表示のやり方を説明します。
RhodoniteはglTF2（.gltf / .glb）とVRM（VRM0.x / VRM1.0）をサポートしています。

## glTFのインポート方法

### GltfImporterを使う
一番簡単な方法は、GltfImporterクラスを使うことです。
このクラスはファイルの種類（glTF2、GLB、VRMなど）を自動的に判定して適切にロードします。
このクラスのimportFromUrlメソッドはawaitを使って呼び出すとExpression型のオブジェクトを返します。
このexpressionはそのまま`engine.process`メソッドに渡して描画できます。

```typescript
const expression = await Rn.GltfImporter.importFromUrl(engine, gltfUrl, loadOption);
```

## Gltf2Importerを使う

glTF2に決めうちしたGltf2Importerもあります。これはexpressionではなく、[RnM2](https://github.com/actnwit/RhodoniteTS/blob/main/src/types/RnM2.ts)という独自形式のデータを返します。
RnMはglTF2の各項目のインデックスで結ばれた論理的な接続関係を、実際のオブジェクトの参照として解決した状態のglTFデータです。
これをModelConverterに渡すことで読み込んだglTFのシーングラフのルートのEntityを得ます。

```typescript
    const rnm = await Rn.Gltf2Importer.importFromUrl(
      '../../../assets/gltf/glTF-Sample-Models/2.0/BoxAnimated/glTF/BoxAnimated.gltf'
    );
    const rootGroup = await Rn.ModelConverter.convertToRhodoniteObject(engine, rnm);

    const expression = new Rn.Expression();
    const renderPass = new Rn.RenderPass(engine);
    renderPass.addEntities([rootGroup]);
    expression.addRenderPasses([renderPass]);
```

## AssetLoaderを使う

[AssetLoader](/ja/docs/core_concepts/asset_loader/)を使うと、複数のアセットを一括で読み込むことができます。`Rn.defaultAssetLoader`はグローバルに利用できるAssetLoaderのインスタンスです。

```typescript
const assets = await Rn.defaultAssetLoader.load({
  gltf: Rn.GltfImporter.importFromUrl(engine, gltfUrl, loadOption),
  vrm: Rn.GltfImporter.importFromUrl(engine, vrmUrl, loadOption),
});

const expressions = [
  assets.gltf,
  assets.vrm,
];

engine.process(expressions);
```

### AssetLoader.loadArrayを使う

AssetLoaderのloadArrayメソッドを使うと、複数のアセットを配列形式で受け取ることができます。

```typescript
const expressions = await Rn.defaultAssetLoader.loadArray([
  Rn.GltfImporter.importFromUrl(engine, gltfUrl, loadOption),
  Rn.GltfImporter.importFromUrl(engine, vrmUrl, loadOption),
]);

engine.process(expressions);
```
