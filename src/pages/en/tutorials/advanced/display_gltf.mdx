This section explains how to display glTF in Rhodonite.
Rhodonite supports glTF2 (.gltf / .glb) and VRM (VRM0.x / VRM1.0).

## How to import glTF

### Using GltfImporter
The easiest way is to use the GltfImporter class.
This class automatically determines the file type (glTF2, GLB, VRM, etc.) and loads it appropriately.
The importFromUrl method of this class returns an Expression object when called using await.
This expression can be passed directly to the `engine.process` method for drawing.

```typescript
const expression = await Rn.GltfImporter.importFromUrl(engine, gltfUrl, loadOption);
```

## Use Gltf2Importer

There is also the Gltf2Importer, which is specific to glTF2. It returns data in a proprietary format called [RnM2](https://github.com/actnwit/RhodoniteTS/blob/main/src/types/RnM2.ts) rather than an expression.
RnM2 is the glTF2 data in which the logical connection relationships between the indexes of the glTF items are resolved to references to the actual objects.
This is passed to ModelConverter to obtain the Entity of the root of the scene graph of the read glTF.

```typescript
    const rnm = await Rn.Gltf2Importer.importFromUrl(
      '../../../assets/gltf/glTF-Sample-Models/2.0/BoxAnimated/glTF/BoxAnimated.gltf'
    );
    const rootGroup = await Rn.ModelConverter.convertToRhodoniteObject(engine, rnm);

    const expression = new Rn.Expression();
    const renderPass = new Rn.RenderPass(engine);
    renderPass.addEntities([rootGroup]);
    expression.addRenderPasses([renderPass]);
```

Usually, it is recommended to use GltfImporter, which automatically determines the type and outputs the final expression.

## Using AssetLoader

Using [AssetLoader](/en/docs/core_concepts/asset_loader/), you can load multiple assets at once. `Rn.defaultAssetLoader` is a globally available AssetLoader instance.

```typescript
const assets = await Rn.defaultAssetLoader.load({
  gltf: Rn.GltfImporter.importFromUrl(engine, gltfUrl, loadOption),
  vrm: Rn.GltfImporter.importFromUrl(engine, vrmUrl, loadOption),
});

const expressions = [
  assets.gltf,
  assets.vrm,
];

engine.process(expressions);
```

### Using AssetLoader.loadArray

Using the loadArray method of AssetLoader, you can receive multiple assets in array format.

```typescript
const expressions = await Rn.defaultAssetLoader.loadArray([
  Rn.GltfImporter.importFromUrl(engine, gltfUrl, loadOption),
  Rn.GltfImporter.importFromUrl(engine, vrmUrl, loadOption),
]);

engine.process(expressions);
```
