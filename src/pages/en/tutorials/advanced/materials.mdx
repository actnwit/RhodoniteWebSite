## Create Material

Rhodonite has many material classes. To generate them, use the [MaterialHelper object](https://actnwit.github.io/RhodoniteTS/api/variables/default.MaterialHelper.html).

```typescript
const material = Rn.MaterialHelper.createPbrUberMaterial(engine);
```

### Importing material factories for tree shaking

`MaterialHelper` references every material factory, so using it keeps all materials in the bundle. To let a bundler leave out the materials you do not use, import the factory function directly.

```typescript
import { createPbrUberMaterial } from 'rhodonite';

const material = createPbrUberMaterial(engine);
```

Node-based materials and MToon are exported from the `rhodonite/optional-materials` subpath (for example, `import { createMToon1Material } from 'rhodonite/optional-materials'`).

## Setting shader parameters to Material

Shader parameters are done for the Material class that holds the shader.

```typescript
material.setParameter("baseColorFactor", Rn.Vector4.fromCopy4(1, 1, 1, 1));
```

To pass the texture to the shader, do the following

```typescript
const rnTexture = await Rn.Texture.loadFromUrl(engine, '/path/to/texture.png');
const rnSampler = new Rn.Sampler(engine, {
   magFilter: Rn.TextureParameter.Linear,
   minFilter: Rn.TextureParameter.Linear,
   wrapS: Rn.TextureParameter.ClampToEdge,
   wrapT: Rn.TextureParameter.ClampToEdge,
});
rnSampler.create();

material.setTextureParameter("baseColorTexture", rnTexture, rnSampler);
```

## Apply Material

The created materials can be used in Primitive and MeshHelper class methods.

```typescript
const primitive = Rn.Primitive.createPrimitive(engine, {
  indices: indices,
  attributeSemantics: [Rn.VertexAttribute.Position.XYZ],
  attributes: [positions],
  primitiveMode: Rn.PrimitiveMode.Lines,
});
primitive.material = material;
```

```typescript
const sphere = Rn.MeshHelper.createSphere(engine, {
    radius: 1,
    widthSegments: 10,
    heightSegments: 10,
    material: material
  })
```
