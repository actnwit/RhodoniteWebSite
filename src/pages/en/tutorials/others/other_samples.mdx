That's all for the tutorial, but if you want more reference code, take a peek in the [samples](https://github.com/actnwit/RhodoniteTS/tree/main/samples) directory of the Rhodonite project! The samples directory is a good place to start. There are a variety of sample source codes to help you with your coding.

After cloning the Rhodonite project, type the following commands under the project to build the library and the samples and start the local server (Node.js 22 or later and pnpm are required).

```bash
$ pnpm install
$ pnpm run build
$ pnpm run watch-samples
```

Go to `http://localhost:8082` to see the sample in action. When you are finished, press ctrl + c.
